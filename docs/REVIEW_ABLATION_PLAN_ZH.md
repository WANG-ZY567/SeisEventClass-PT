# 审稿补充：组件消融实验计划

目标：在 S 到时有效、按事件时间顺序划分的 EVT6 数据集上，分别检验 GPT-2 预训练、长程 token 交互、多尺度标记器和 LoRA 的贡献。主指标为波形级 Accuracy 与 Macro-F1；同时报告事件级平均概率聚合指标、可训练参数量和训练资源开销。

所有消融使用相同数据集、同一随机种子、数据增强、归一化、学习率计划、训练轮数和验证集 Accuracy 选点规则。测试集仅在选定检查点后运行一次。

| 名称 | GPT-2 | token 交互 | 标记器 | 主干更新 | 当前状态 |
|---|---|---|---|---|---|
| Full | 预训练 | 全局 GPT-2 | 四尺度并联 | LoRA | 已有主模型结果；需按统一训练协议重跑配对对照 |
| A1 Random-init | 随机初始化 | 全局 GPT-2 | 四尺度并联 | 全参数训练 | 需在最终数据集重跑 |
| A2 Local-attention | 预训练 | 局部注意力掩码 | 四尺度并联 | LoRA | 待实现 |
| A3 Single-scale | 预训练 | 全局 GPT-2 | 每层单一卷积尺度 | LoRA | 已实现，待训练 |
| A4 Head-only | 预训练 | 全局 GPT-2 | 四尺度并联 | 冻结 GPT-2，仅训练头与卷积标记器 | 待训练 |
| A5 Full fine-tune | 预训练 | 全局 GPT-2 | 四尺度并联 | GPT-2 全参数微调 | 待训练 |

`SeisMoLLM_evt6_single_scale` 是 A3。它把每个 `Multi_Scale_Conv_Block` 的四条平行卷积分支改成一条基础核卷积分支；波形输入、卷积深度、GPT-2 层数、预训练权重、LoRA、六分类头和损失均保持一致。该变化会降低参数量，因此论文应同时报告参数量，避免把它表述为严格等参数比较。
